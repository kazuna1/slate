# Slate

**PowerShell in another skin.** Press **Win + Space** anywhere, type a command, hit Enter. It runs in a terminal.

## Install

```powershell
irm https://raw.githubusercontent.com/kazuna1/slate/main/install.ps1 | iex
```

or `winget install kazuna1.Slate` · or `npm i -g kazuna-slate` · or the button above

## Use

| | |
|---|---|
| **Win + Space** | open / close the bar |
| **Enter** | run in a terminal |
| **Tab** | complete folder names |
| **↑ ↓** | history |
| **Esc** | cancel |

Customize anything with `:config`. See [docs/config.md](docs/config.md).
