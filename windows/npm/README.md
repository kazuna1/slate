# kazuna-slate

Installs **[Slate](https://github.com/kazuna1/slate)**, an always-on command bar for the Windows desktop.
Press **Win + Space** anywhere, type a command, hit Enter. It runs in a terminal.

```
npm i -g kazuna-slate
```

The Slate app is installed per-user (no admin) and starts right away.

```
slate              start Slate (installs it first if needed)
slate --update     reinstall this package's version
slate --uninstall  remove the Slate app
```
